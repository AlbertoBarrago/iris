# Security

Iris holds OAuth tokens for Gmail accounts and renders mail from
strangers, so a flaw can expose someone's mail.

Report a vulnerability privately through
[GitHub's security advisories](https://github.com/AlbertoBarrago/iris/security/advisories/new),
not in a public issue. Include the version, the steps that show the
problem, and what an attacker gains.

Only the latest release gets fixes.
